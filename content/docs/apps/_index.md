# 外部アプリケーション

## 就活ID管理表

ES締切、適性検査、マイページID、企業URLを一元管理するためのWebアプリです．

- Googleログイン対応
- ES・適性検査の締切管理
- ステータス管理
- Next.js + Supabase + Vercel

[Launch App →](https://jobhunt.yut4k.com)


## ファイアーエムブレムマップ作製アプリ

攻略サイトやメモを残す際，グリッドマップを用いたいですよね．マップの作製自体は手書きでしないといけませんが，jsonファイルで保存可能です． <br>

**注意**
- ファイルサーバ等まだないので，サイトを移動すると編集データが破棄されます

[Go to "FE Map Maker" -> -> ->](https://femapmaker.yut4k.com)
