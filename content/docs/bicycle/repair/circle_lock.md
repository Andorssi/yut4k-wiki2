# スポークの最大の敵はリング錠
　日々通学していて，ふと自分の前を走る自転車を見ると，後輪が振れていることがあります．当の本人はきっと気づいていないのでしょうが，車輪の死にざまを知る自分からすると，早く直さないと危ないなあと思っています．今回は，そんなスポーク折れに関する話をしていこうと思います．

{{< hint info >}}
「振れている(ふれている)」というのは，車輪がゆがんでいることを言っています．
{{< /hint >}}

## そもそもスポークって？
　下図を見てもらえればわかると思います．スポークとは，針金1本1本のことを言います．また，リムとスポークをつなぎとめているネジのような役割をもつパーツはニップルと呼ばれています． <br>
　車輪というのは，とても繊細なパーツです．スポーク1本1本が力のつり合いをとっています．具体的には，ニップルの締め付け具合で張り調整をします．この作業は**振れ取り**と呼ばれています．つまり，スポークが一本折れるとそこの張力は0になるので，反対側に車輪がゆがみます．また，一か所の張力が弱まることで，他の箇所も連鎖的に崩れていきます．

## ここでタイトル回収
　スポークが折れる原因を考えてみてください．私が思いつく原因をいくつかあげてみます．まあ，そんなないんですけども．

- ぶつかる or ぶつけられる
- 段差を無理に乗り上げる(へりにある意味ぶつける)
- 重さに耐えられずに...
- リング錠(!)

ここで，リング錠が悪さをします．つまり，最大の要因は**鍵をかけっぱなしでペダルを回してしまうこと**です．リングはニップル付近に位置するため，ニップル側(外側)からダメージが加わってポッキリいってしまうわけです．

## 対策
　現状の対策は気を付ける，しかないです．もし，折れたらすぐに修理！これが大きな修理を防ぐ最大のコツです．

## さいごに(私は冗談を言っています)
　今の自転車業界は凝り固まった既存の考えしかできない界隈な気がします．もしかしたら，上流の開発部では様々な検討がされているのかもしれませんが，店舗までその発想が下りてくることはありません．スポーク折れが多くなり，車輪がどんどんダメになっていくのを防ぐためには，そもそもスポークが折れる要因を排除しなければなりません．電動自転車はモーター，バッテリーが搭載されているため，その辺をうまく利用してリング錠を使わずに施錠する方法がないか模索してほしいです．
