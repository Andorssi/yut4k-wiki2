# Packet Tracerを学ぶ
Ciscoが提供するPacket Tracerを使ってネットワーク構築等の勉強をしていきます．Packet Tracerとは，ネットワークシミュレーションソフトウェアで，実際のルータやスイッチを用意しなくても，仮想的なネットワーク機器を配置し，ネットワークを構築・検証できます．

## 見ていただいているあなた
ネットワークに関する基礎的な知識があることを前提にCiscoの機器をシミュレータで触ってみる，iosを学ぶという意義で本ページを作成し始めています．よって，そもそもIP全くわからない！という方には不親切なものになってしまっていると思います．
