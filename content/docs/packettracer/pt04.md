# 4章 VLANの導入

VLAN(Virtual LAN)とは，スイッチのポートなどを論理的なグループに分け，独立したL2NWを構成する技術です．VLANで区切ると，たとえ同じスイッチに接続されていても直接通信できなくなります． <br>
今回は，ルータは使わないです．スイッチでVLANを定義します．

## Packet Tracer上での再現

**手順**

1. 下図の構成を作成．

<div class="center-fig">
    <img src="/figure/packet tracer/pt03/image02.png" alt="PT構成図">
    <p class="caption">Packet tracer上で構築</p>
</div>

2. PCのIPアドレスを設定．IPアドレスはNW構成図参照．(デフォルトGWは空欄でOK)

3. スイッチにVLANを設定．SW0のCLIで以下コマンドを入力．
```python
enable
conf t

vlan 10
name Lab1
exit

vlan 20
name Lab2
exit

end
```

{{< hint info >}}
`vlan 10` : VLAN ID 10を作成 <br>
`name Lab1` : VLANに名前を付ける
{{< /hint >}}

4. ポートをVLANに割り当てる．引き続き以下を入力．

```python
enable
conf t

interface fastEthernet 0/1
switchport mode access
switchport access vlan 10
exit

interface fastEthernet 0/2
switchport mode access
switchport access vlan 20
exit

end
```

{{< hint info >}}
`switchport mode access` : ポートをアクセスポートとして動作させる <br>
`switchport access vlan 10` : そのポートをVLAN 10に所属させる
{{< /hint >}}

5. SW1も同様に設定．
```python
enable
conf t

vlan 10
name Lab1
exit

vlan 20
name Lab2
exit

interface fastEthernet 0/1
switchport mode access
switchport access vlan 10
exit

interface fastEthernet 0/2
switchport mode access
switchport access vlan 20
exit

end
```

6. `show vlan brief`でVLANの所属状況を確認．SW上で確認．

7. Trunkポートの設定．

{{< hint info >}}
これは，2台のスイッチ間で複数のVLAN通信を転送できるようにするものです．Trunkポートは複数のVLANフレームを1本の物理リンクで転送できます．
{{< /hint >}}

SW0の設定．

```python
enable
conf t

interface gigabitEthernet 0/1
switchport mode trunk
switchport trunk allowed vlan 10,20
no shutdown
exit

end
```

SW1の設定．
```python
enable
configure terminal

interface gigabitEthernet 0/1
switchport mode trunk
switchport trunk allowed vlan 10,20
no shutdown
exit

end
```

`switchport trunk allowed vlan 10,20`とすることで，Trunk上で転送を許可するVLANを10と20に制限している．この指定を省略すると，基本的にはすべてのVLANが許可される．

8. ここまで終わっていれば，pingが通っているはず．また，異なるVLANのPCにはpingが通らないことを確認する．
