## Packet Tracerで再現する

**手順** <br>
1. PCおよびSwitchは1章と同様のものを使用．Routerは1941を使用します．
2. 有線接続は以下の通りです．

{{< hint info >}}
PC0-Switch0 : Fa0 - Fa0/1 <br>
PC1-Switch0 : Fa0 - Fa0/2 <br>
Switch0-Router0 : Fa0/3 - Gi0/0 <br>
Router0-Switch1 : Gi0/1 - Fa0/1 <br>
Switch1-PC2 : Fa0/2 - Fa0 <br>
{{< /hint >}}

<div class="center-fig">
    <img src="/figure/packet tracer/pt02/image02.png" alt="PT上の構成">
    <p class="caption">Packet Tracer上で再現</p>
</div>

3. ルータ設定を行う．Router0 -> CLIを選択し，以下のコマンドを入力．tab補完が可能

```python
enable
conf t

interface gigabitEthernet 0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit

interface gigabitEthernet 0/1
ip address 192.168.2.1 255.255.255.0
no shutdown
exit

end
```

{{< hint info >}}
enable : 特権モードへ移行 <br>
conf t : グローバル設定モードへ移行(configure terminal) <br>
interface : 設定するインタフェースを選択 <br>
ip address : IPアドレスとサブネットマスクを設定 <br>
no shutdown : インタフェースの有効化 <br>
exit : 1つ前の設定モードへ戻る <br>
end : 特権モードへ戻る <br>
{{< /hint >}}

4. 設定の確認．ルータのCLIで以下コマンドを入力
```python
# GigabitEthernet0/0とGigabitEthernet0/1がup/upならOK
show ip interface brief

# ルーティングテーブルの表示
show ip route

# 設定の保存
copy running-config startup-config
```

5. 疎通確認．以下はPC0からPC2に対するping．
```bash
ping 192.168.2.10
```

## 確認問題

問1 L2スイッチがEthernetフレームの転送先を判断するために，主に使用する情報はどれか．

- A．送信元IPアドレス
- B．宛先MACアドレス
- C．宛先ポート番号
- D．サブネットマスク

{{< spoiler >}}
B: 通常のレイヤ2スイッチは，宛先MACアドレスをMACアドレステーブルと照合し，転送先ポートを判断する．
{{< /spoiler >}}

問2 PC0が`192.168.1.10/24`，PC1が`192.168.1.11/24`であり，同じスイッチに接続されている．PC間通信について正しい記述はどれか．

- A．必ずルータが必要になる
- B．デフォルトゲートウェイを設定しないと通信できない
- C．同じサブネット内であるため，ルータなしで通信できる
- D．IPアドレスが異なるため通信できない

{{< spoiler >}}
C: `192.168.1.10/24`と`192.168.1.11/24`は，どちらも`192.168.1.0/24`に属する．同一サブネット内であれば，ルータを経由せず通信できる．
{{< /spoiler >}}

問3 PC0（`192.168.1.10/24`）からPC2（`192.168.2.10/24`）へ通信する．PC0のデフォルトゲートウェイは`192.168.1.1`である．PC0が最初にEthernetフレームを送信する際，宛先MACアドレスとして使用する機器はどれか．ただし，宛先までの特別な経路設定はないものとする．

- A．PC2
- B．`192.168.1.1`のルータインターフェース
- C．`192.168.2.1`のルータインターフェース
- D．DNSサーバ

{{< spoiler >}}
B: PC0から見てPC2は異なるサブネットにあるため，PC0はデフォルトゲートウェイへEthernetフレームを送信する．このときEthernetフレームの宛先MACアドレスは`192.168.1.1`を持つルータインターフェースのMACアドレスとなる．なお，IPパケットの宛先IPアドレスはPC2のままである．
{{< /spoiler >}}

問4 Router0の`GigabitEthernet0/1`が`administratively down/down`になっていた．インターフェースを有効化するコマンドはどれか．

- A．`shutdown`
- B．`no shutdown`
- C．`enable interface`
- D．`ip route`

{{< spoiler >}}
B: `administratively down`は，インターフェースが管理上無効化されていることを示す．インターフェース設定モードで`no shutdown`を実行して有効化する．
{{< /spoiler >}}

問5 ルータの`GigabitEthernet0/0`に`192.168.2.1/24`が設定されている状態で，`GigabitEthernet0/1`に`192.168.2.2/24`を設定しようとすると，`overlaps`というエラーが表示された．原因はどれか．

- A．スイッチが接続されていない
- B．2つのルータインターフェースに重複するサブネットを割り当てようとした
- C．IPアドレスがプライベートアドレスである
- D．サブネットマスクが`255.255.255.0`である

{{< spoiler >}}
B: `192.168.2.1/24`と`192.168.2.2/24`は，どちらも`192.168.2.0/24`に属する．通常のルータ設定では，異なるL3インターフェースに重複するサブネットを割り当てられない．
{{< /spoiler >}}

問6 ルータで`show ip route`を実行したところ，次の表示があった．

```text
C 192.168.2.0/24 is directly connected, GigabitEthernet0/1
```

先頭の`C`が意味するものはどれか．

- A．静的ルート
- B．直接接続されたネットワーク
- C．OSPFによって学習した経路
- D．デフォルトルート

{{< spoiler >}}
B: ルーティングテーブルの`C`はConnectedを表し，ルータに直接接続されたネットワークを示す．静的ルートは通常`S`で示される．
{{< /spoiler >}}

問7 PC0が同一LAN内のPC1に`ping`を送る際，PC1のIPv4アドレスに対応するMACアドレスを調べるために使用するプロトコルはどれか．

- A．DNS
- B．TCP
- C．ARP
- D．OSPF

{{< spoiler >}}
C: ARP（Address Resolution Protocol）は，同一リンク上でIPv4アドレスに対応するMACアドレスを解決するために使用する．一方，`ping`ではICMP Echo RequestおよびEcho Replyを使用する．
{{< /spoiler >}}

問8 Router0の`GigabitEthernet0/0`と`GigabitEthernet0/1`にそれぞれ`192.168.1.1/24`と`192.168.2.1/24`を設定し，両方が`up/up`になっている．この2つのネットワーク間のルーティングについて正しい記述はどれか．

- A．必ず静的ルートを追加する必要がある
- B．OSPFを設定しないと通信できない
- C．両方のネットワークが直接接続経路として登録される
- D．ルータは1つのネットワークしか扱えない

{{< spoiler >}}
C: 設定済みのインターフェースが`up/up`で動作していれば，該当するネットワークは直接接続経路としてルーティングテーブルに登録される．今回の2つのサブネット間の通信に静的ルートやOSPFは不要である．ただし，各PCのアドレスとデフォルトゲートウェイが正しく設定されている必要がある．
{{< /spoiler >}}
