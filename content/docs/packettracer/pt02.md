## Packet Tracerで再現する

**手順** <br>
1. PCおよびSwitchは1章と同様のものを使用．Routerは1941を使用します．
2. 有線接続は以下の通りです．

{{< hint info >}}
PC0-Switch0 : Fa0 - Fa0/1 <br>
PC1-Switch0 : Fa0 - Fa0/2 <br>
Switch0-Router0 : Fa0/3 - Gi0/0 <br>
Router0-Switch1 : Gi0/1 - Fa0/1 <br>
Switch1-PC2 : Fa0/2 - Fa0 <br>
{{< /hint >}}

<div class="center-fig">
    <img src="/figure/packet tracer/pt02/image02.png" alt="PT上の構成">
    <p class="caption">Packet Tracer上で再現</p>
</div>

3. ルータ設定を行う．Router0 -> CLIを選択し，以下のコマンドを入力

```python
enable
conf t

interface gigabitEthernet 0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit

interface gigabitEthernet 0/1
ip address 192.168.2.1 255.255.255.0
no shutdown
exit

end
```

{{< hint info >}}
enable : 特権モードへ移行 <br>
conf t : グローバル設定モードへ移行(configure terminal) <br>
interface : 設定するインタフェースを選択 <br>
ip address : IPアドレスとサブネットマスクを設定 <br>
no shutdown : インタフェースの有効化 <br>
exit : 1つ前の設定モードへ戻る <br>
end : 特権モードへ戻る <br>
{{< /hint >}}

4. 設定の確認．ルータのCLIで以下コマンドを入力
```python
# GigabitEthernet0/0とGigabitEthernet0/1がup/upならOK
show ip interface brief

# ルーティングテーブルの表示
show ip route

# 設定の保存
copy running-config startup-config
```

5. 疎通確認．以下はPC0からPC2に対するping．
```bash
ping 192.168.2.10
```
