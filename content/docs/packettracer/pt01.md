# 1章 つないでみる

2台のPCを同一スイッチにつないで，PC間で通信ができることを確認してみます． <br>

**手順** <br>
1. End DevicesからPC-PTを2台設置する <br>
2. Network Devices -> Switchesから2960を設置する <br>
3. ConnectionsからCopper Straight-Throughを選択し，PCとSwitchをつなぐ <br>

{{< hint info >}}
PC0-Switch0はそれぞれFastEthernet0とFastEthernet0/1を接続<br>
PC1-Switch1はそれぞれFastEthernet0とFastEthernet0/2を接続
{{< /hint >}}

<div class="center-fig">
    <img src="/figure/packet tracer/pt01/image01.png" alt="機器設置">
    <p class="caption">設置まで行ったらこうなるはず</p>
</div>

4. PC0を選択しDesktop -> IP Configuration からIPアドレスを設定する

{{< hint info >}}
IPv4 Address : 192.168.1.10 <br>
Subnet Mask : 255.255.255.0(つまり，/24) <br>
Default GatewayとDNS ServerはそのままでOK <br>
{{< /hint >}}

<div class="center-fig">
    <img src="/figure/packet tracer/pt01/image02.png" alt="IP設定">
    <p class="caption">PC1も同様にやる</p>
</div>

5. PC1も同様に設定する

{{< hint info >}}
IPv4 Address : 192.168.1.11 <br>
Subnet Mask : 255.255.255.0 <br>
Default GatewayとDNS ServerはそのままでOK <br>
{{< /hint >}}

6. 疎通確認を行う．PC0 -> Desktop -> Command Promptを選択し，以下コマンドを入力
```bash
ping 192.168.1.1
```
